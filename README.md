# 🍽️ Jenna's Recipe Website

Jenna’s Recipe Website is a recipe discovery platform built using HTML, CSS, Bootstrap, and JavaScript. The website helps users explore featured recipes and search for meal ideas using ingredients they already have through Spoonacular API integration.


## ✨ Features

* 🍳 Featured recipe cards using live API data
* 🔍 Ingredient-based recipe search
* 📝 Real-time ingredient list updates
* 📱 Responsive Bootstrap layout
* 📬 Contact section with newsletter signup
* 🌐 Social media links and footer information


## 📄 Pages

### 🏠 Home

* Hero section with recipe-themed media
* Website introduction
* Service cards
* Contact and newsletter section

### 👩‍🍳 About

* Jenna’s story and cooking journey
* Featured favorite recipes
* Recipe cards generated through the Spoonacular API

### 🍲 Recipes

* Ingredient input system
* Add Ingredient, Recipe Search, and Start Over functionality
* Displays recipe results with images and missing ingredients
